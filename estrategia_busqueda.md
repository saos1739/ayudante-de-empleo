# Estrategia de Búsqueda y Monitoreo de Empleo

Esta guía detalla los comandos booleanos de búsqueda, filtros y URLs directas para monitorear ofertas que encajen al 100% con el perfil de **Santiago Agustín Rojas Casas**.

---

## 1. Búsquedas Booleanas Optimizadas por Plataforma

### A. LinkedIn Jobs
Copiar y pegar en la barra de búsqueda de LinkedIn con ubicación `Buenos Aires, Provincia de Buenos Aires, Argentina` o `Capital Federal, Argentina`:

**Búsqueda 1: Full Stack / Node.js / React Junior**
```text
(Junior OR Trainee OR "Jr" OR "Sin experiencia") AND (Node OR "Node.js" OR React OR Express) AND (Desarrollador OR Developer OR Programmer)
```

**Búsqueda 2: Python / Backend / Data Junior**
```text
(Junior OR Trainee OR "Jr") AND (Python OR Django) AND (Desarrollador OR Developer OR Backend)
```

**Filtros clave en LinkedIn:**
- *Fecha de publicación:* Última semana (o últimas 24 hs para postulación rápida).
- *Nivel de experiencia:* Prácticas / Sin experiencia / Inicial (Entry Level).
- *Ubicación:* Híbrido, Presencial (CABA / Zona Sur) y Remoto.

---

### B. Bumeran & Zonajobs (Navent Group)
En ambas plataformas, buscar dentro del área **"Tecnología, Sistemas y Telecomunicaciones"**:
- **Término 1:** `Desarrollador Junior`
- **Término 2:** `Trainee Sistemas` o `Trainee Programacion`
- **Término 3:** `Junior Node` o `Junior React` o `Junior Python`
- **Ubicación:** Capital Federal y GBA Zona Sur / GBA General.
- **Filtro de experiencia:** "Menos de 1 año" o "Sin experiencia".

---

### C. Computrabajo Argentina
Buscar con el filtro geográfico `Capital Federal` o `Buenos Aires`:
- **Búsqueda directa:** `Programador Junior` o `Desarrollador Trainee`
- **Palabras clave específicas:** `Node.js`, `React`, `Python`, `Web Trainee`
- **Tip para Computrabajo:** Mantener el CV de Computrabajo actualizado semanalmente con las palabras clave exactas (`Node.js`, `React`, `Python`, `SQL`, `AWS`, `Git`) para que aparezcas primero en los filtros de las consultoras de selección.

---

### D. Get on Board (Tech & Startups)
Plataforma especializada en IT con alta presencia en Argentina y Latam:
- Filtro: **Nivel de experiencia: Junior / Trainee**
- Categorías: **Programación Backend / Frontend / Full Stack**
- Modalidad: **Argentina (Remoto o Híbrido CABA)**
- URL directa: [getonbrd.com/jobs-programming](https://www.getonbrd.com/jobs-programming)

---

### E. Upwork & Freelancer (Proyectos en USD / Horas)
Para ganar experiencia inicial y proyectos cobrados en dólares aprovechando el inglés B2:
- **Términos de búsqueda:**
  - `entry level web developer`
  - `react landing page` / `react bug fix`
  - `node js api endpoint`
  - `python script automation` / `python scraping`
- **Filtros en Upwork:**
  - *Experience Level:* Entry Level ($)
  - *Job Type:* Fixed-Price (hitos concretos) o Hourly
  - *Proposals:* Less than 5 (para postular primero con alta tasa de respuesta)

---

## 2. Matriz de Compatibilidad (Score de Match)

Para cada vacante identificada, evaluamos la compatibilidad de 1 a 100%:

| Criterio | Peso | Requisito Ideal |
| :--- | :---: | :--- |
| **Nivel / Seniority** | 30% | Trainee, Junior, Entry Level, Estudiante avanzado de sistemas. |
| **Core Stack** | 30% | JavaScript (Node/Express/React) o Python (Django/APIs) + SQL. |
| **Ubicación / Traslado** | 20% | Remoto, Híbrido o Presencial accesible (CABA o Zona Sur). |
| **Diferenciadores** | 10% | Cloud (AWS/GCP), Git/GitHub, Metodologías Ágiles. |
| **Idioma** | 10% | Español nativo; inglés técnico B2 valorado. |

- **Score >= 80%:** **Prioridad Alta.** Postulación inmediata + mensaje directo a recruiter / líder técnico.
- **Score 60% - 79%:** **Prioridad Media.** Postulación adaptando la carta de presentación destacando habilidades transferibles y capacidad de aprendizaje rápido.
- **Score < 60%:** **Descartar.** Exige tecnologías no vistas o seniority semi-senior/senior estricto (+3 años).
